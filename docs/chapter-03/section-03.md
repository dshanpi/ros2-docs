## 3.3.1 什么是进程？

可以把计算机中的 <strong>程序</strong> 想象成一份 “剧本”（比如桌面上的 firefox 图标），而 <strong>进程</strong> 就是这场剧本的 “舞台表演”—— 当你双击图标启动浏览器时，剧本就被 “执行” 了，此时系统中就诞生了一个 浏览器进程。

注意：在这里要区分“程序”和“进程”。

简单来说：进程是 “正在执行的程序”，是操作系统分配资源的基本单位。

<strong>进程的三个核心要素：</strong>

1. 进程 ID（PID）：

每个进程诞生时，系统会分配一个唯一的数字编号（如 1234），就像每个人的身份证号，用于区分不同进程。

2. 父子关系：

进程可以 “生娃”！通过 fork 系统调用，一个进程（父进程）能复制出一个几乎相同的子进程。

举例：启动浏览器主进程（父进程，假设 PID=5000），打开新标签页时，主进程会创建子进程（如 PID=5001）加载网页。

3. 资源占用：

进程运行时需要 “物资”，比如 CPU 计算能力、内存空间、打开的文件（如网页文件、配置文件）等，这些统称为 <strong>系统资源</strong>。

## 3.3.2 进程的生命周期

就像人有从出生到成长的不同阶段，一个进程在操作系统中运行时，也会经历不同的“人生阶段”。为了高效地管理成千上万个进程，操作系统定义了几种进程的<strong>主要状态</strong>。理解这些状态，是理解进程生命周期的第一步。

通常，我们认为一个进程主要有以下五种状态：

[![3.3.2 进程的生命周期](/img/manual/image65.png)](/img/manual/image65.png)

1. <strong>新建状态：</strong>进程刚被创建，但尚未准备好运行（操作系统正在为其分配资源、创建进程控制块 PCB）。

2. <strong>就绪状态</strong>：进程已准备好运行，只等 CPU 分配时间片（资源已就绪，万事俱备，只欠 CPU）。

3. <strong>运行状态：</strong>进程正在占用 CPU 执行代码（真正 “干活” 的阶段）。

4. <strong>阻塞/等待状态：</strong>进程因等待某个事件（如 I/O 完成、信号、锁释放）而暂停运行，即使 CPU 空闲也无法执行。

5. <strong>终止状态：</strong>进程执行完毕或被强制结束，资源即将被回收。

## 3.3.3 ps查看进程

ps命令可以用于查看当前系统中进程的“静态快照”。如下图所示：

- a：显示所有用户的进程

- u：显示用户相关信息

## 3.3.4 top查看进程

top命令就像实时更新的 “进程仪表盘”，类似 Windows 的任务管理器，会动态显示进程状态。如下图所示：

[![3.3.4 top查看进程](/img/manual/image67.png)](/img/manual/image67.png)

常用按键：

- P：按 CPU 使用率排序（找出最 “吃 CPU” 的进程）。

- M：按内存使用率排序（找出最 “吃内存” 的进程）。

- k：输入进程的 PID，强制终止该进程（等价于 kill 命令）。

- q：退出 top。
